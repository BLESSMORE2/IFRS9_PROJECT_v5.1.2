How Automation Runs

The watchdog remains available inside Django, while the database controls above decide whether work is executed.

Only one scheduler worker may hold the process lock, preventing duplicate workers across Django processes.
Each schedule also uses its own execution lock, preventing manual and automatic runs from overlapping.
If an endpoint uses reporting_date, its saved schedule supplies the configured run date, previous day, or fixed date.
