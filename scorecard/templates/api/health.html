Health Overview

This page gives a quick operational view of your saved endpoints so you can spot issues without opening each section one by one.

Last test time shows the most recent endpoint connection test from the Endpoints page.
Last import time shows the most recent manual or scheduled import run saved in import history.
Last scheduled run shows the latest run executed through Automation for that endpoint.
Trend is based on the recent saved import runs for that endpoint.
