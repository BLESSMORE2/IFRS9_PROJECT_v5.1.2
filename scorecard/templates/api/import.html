Import Notes

The endpoint decides the destination table. Loading pulls all pages and upserts records into the target table.

Use Load To Table to import all records page by page.
Corporate endpoints load into CustomerCorporate. Individual endpoints load into CustomerIndividual.
Preview and imported values are normalized before saving, so the data stored in the target table follows the same cleaning rules shown across the API module.
Because the schema requires it, the backend maintains the linked Customer row automatically in the background.
