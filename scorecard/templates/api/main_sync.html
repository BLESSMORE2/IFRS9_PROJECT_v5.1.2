Sync Rule

The main customer table only syncs when all required source imports are available for the same reporting date.

Required customer sources: {{ required_targets|join:", " }}.
If one source has not loaded yet, the sync waits and the status stays in Waiting For Sources.
Once both are loaded for the same reporting date, the countdown starts from the latest completed source import.
When the configured delay finishes, the system syncs the main customer table automatically through the Django scheduler service.
