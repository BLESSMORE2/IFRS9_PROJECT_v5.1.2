How This Works

This page stores the base connection only. Endpoints are created separately, and retrieval uses the saved settings automatically.

`Base URL` is the API host, for example `http://192.168.4.48:8090`.
`Header Name` is how the secret key is sent, for example `X-API-KEY`.
`Secret Key` is stored in settings so you do not have to repeat it on every endpoint or retrieval screen.
Reusable parameters such as `reporting_date`, `page`, `page_size`, or `branch_code` can be defined once here and reused professionally across testing and retrieval.
`Request timeout (seconds)` means how long the system waits for the API to respond before stopping the request and marking it as failed.
`Endpoint test timeout (seconds)` controls how long the server spends checking an endpoint before the test is stopped.
`Browser wait timeout (seconds)` controls how long the page waits before cancelling a test request in the browser and showing failure quickly.
